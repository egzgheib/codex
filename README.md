# Fitness Goal Tracker

A lightweight single-page web app for tracking fitness goals and the individual steps needed to reach them.

## Features

- Create fitness goals with an optional target date.
- Break each goal into concrete step-by-step tasks.
- Mark steps complete with checkboxes.
- Automatic progress bar and completion percentage for every goal.
- Data saved in browser `localStorage`.

## Run locally

Open `index.html` in a web browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000`.
